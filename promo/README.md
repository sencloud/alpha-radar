# 推广素材

这个目录放对外发布用的素材，全部由脚本生成，可复现。

| 文件 | 用途 | 规格 |
|---|---|---|
| `zhihu-cover.png` | 知乎文章 / 专栏封面 | 1200×675（16:9） |
| `zhihu-cover@2x.png` | 高清屏 / 二次裁切 | 2400×1350 |
| `equity.csv` | 封面用的真实资金曲线数据 | 每次生成时落盘，便于离线重制 |
| `cover_meta.json` | 封面用的笔数 / PF / 分年 | 由回测结果自动生成 |
| `make_cover.py` | 封面生成器 | — |

## 生成

```bash
python promo/make_cover.py
```

曲线与数字都来自**真实回测**（UT Bot @ 棕榈油 5 分钟，2022–2026）。
首次运行会调 Tushare 拉数据并落盘 `equity.csv` / `cover_meta.json`；
之后离线即可重新生成。没有 token 时会退化成示意曲线并在终端提示。

**封面上的每个数字都是从回测结果算出来的，不允许手写。**
素材与代码结论不一致是这类项目最容易翻车的地方 —— 之前手写的
「2022 顶点」就标错过一次（真实峰值在按市值计价的 2025-03），
所以改成由 `_meta_from_result()` 直接产出。

## 封面讲了什么

知乎封面在信息流里很小，所以只放三层信息：

1. **一句钩子**：不找圣杯，只做证伪 —— 这是这个项目最反直觉、也最容易被记住的定位
2. **一张真实的资金曲线**：2022 年冲高、之后连亏三年 —— 图本身就是论点
3. **一行出处**：策略来源、数据源、agent 底座、仓库地址

刻意**没有**放"年化 XX%""胜率 XX%"这类数字：这个项目的可信度来自
「我愿意把亏损曲线印在封面上」，而不是来自一个漂亮的收益率。
