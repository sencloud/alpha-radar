# 实战结论记录

数据：Tushare 期货主力连续（1 分钟 / 5 分钟 / 15 分钟）。
标的：棕榈油 P.DCE 为主，2022-01 ~ 2026-10，15 个主力合约切换。
成本：双边 1 跳滑点 + 手续费，逐笔计入。

> 记录规则：**失败也写**。下面每一条都附了可复现的命令。
>
> 自 2026-10-10 起，五道闸门由 `alpharadar/judge.py` 按 `config/gates.json` 自动判定，
> 本文 1–8 条的数字同步在 `docs/archive/curated.json`（对外精选档案的唯一来源）。
> 第 6、7 条原先用的是 CC BY-NC-SA 4.0 脚本的移植（`false_breakout` / `orb`），
> 对外档案已改指向按公开思路独立实现的 `breakout_fade` / `orb_classic`，
> **数字待在生产环境重跑后更新**。

## 1. UT Bot（趋势族）@5min — 唯一在千笔样本上 PF>1

```
alpharadar run --symbol P.DCE --strategy utbot --freq 5min --start 20220101
```

- 1060 笔，胜率 42.7%，PF 1.05，每手 **+1.06 点**，最大回撤 −18.5%
- 分年：2022 **+23,554** / 2023 +5,915 / 2024 −2,666 / 2025 −3,885 / 2026 −11,691
- 判断：**不能实盘**。全部利润来自 2022，最近三年连亏，
  收益回撤比 0.45。但它证明了 5 分钟尺度上"宽跟踪止损 + 趋势跟随"
  这个结构本身有微弱优势，值得继续挖。

## 2. 趋势族 + ER 体制闸门 — 目前最好的一档

```
alpharadar run --symbol P.DCE --strategy utbot --freq 5min --start 20220101 \
  --set use_regime=1 --set er_min=0.25 --set atr_ratio_min=0
```

- 55 笔，PF **1.578**，每手 +13.75 点，正年数 **4/5**
- 代价：样本只剩 55 笔（约 12 笔/年），统计上偏薄
- 判断：**方向对，样本不足**。下一步应该跨品种验证，而不是继续调阈值。

## 3. ATR 倍数敏感性 — 单调，3.0 最优

3 个变体 × 3 个 ATR 周期 × 5 个倍数 = 45 组。倍数 1.0/1.5 一律惨败（PF 0.55~0.88），
2.0 勉强，3.0 顶点。**紧止损是成本绞肉机。**

## 4. 分批止盈 — 负贡献

TP1/TP2/TP3 各平 1/3（1/2/3 ×ATR）：PF 从 0.905 掉到 0.852。
机制：盈利单被提前砍掉，亏损单照吃满止损。分批只在"少数单子能走很远"的
分布下才划算，本形态不具备。

## 5. 保本止损 — 重灾

浮盈 8 点推平：胜率 47.8% → 31.2%，PF 0.75 → 0.65。
与工程内 5 分钟 BOLL 策略的历史记录完全一致（当时胜率掉到 1%）。

## 6. 假突破反向（False Breakout）— 失败

> 原创实现：`--strategy breakout_fade`（Turtle Soup 思路，MIT）。下面是旧移植版的数字，待重跑。

```
alpharadar run --symbol P.DCE --strategy false_breakout --freq 1min --start 20220101
```

- @1min：1931 笔、PF 0.692、每手 −4.31 点、**0/5 年为正**
- @5min：462 笔、PF 0.849
- 失败原因：信号在价格已经收回之后才触发，等于在反方向的"最大不利偏移"处入场。
  棕榈油的突破确实偏假，但**假完之后沿原方向延续**，不是回头。

## 7. 开盘区间突破（ORB）— 失败

> 原创实现：`--strategy orb_classic`（Crabel ORB 思路，MIT）。下面是旧移植版（`orb`）的数字，待重跑。

- @5min：1223 笔、胜率 **49.3%（全场最高）**、PF 0.889、**0/5 年为正**
- 失败原因：赔率结构不成立。突破后回撤到对侧止损太常见，
  赢的行程又常在一倍区间高度之前衰竭。**高胜率掩盖不了负期望。**

## 8. 冰点反转（原创，形态来自沪银 1 分钟图）— 1 分钟不可交易

- @1min：1718 笔、PF 0.746、每手 −3.72 点
- 事件研究：冰点事件前向收益最大 +0.30 点（5 根），突破入场 −1.02 点，
  而往返成本 4.5 点 —— **形态边际比成本小一个数量级**
- 回踩再入（retest）能把盈亏比从 0.81 修到 1.29，但胜率跌破平衡线，PF 反而降
- 判断：**盈亏比倒挂是症状，病根是这个形态在 1 分钟尺度没有边际。**

## 9. 成本占比表 — 为什么 1 分钟是死路

棕榈油 1 分钟平均振幅 7.8 点，往返成本 4.5 点，占比 **58%**。
5 分钟占比 25%，15 分钟 13%（但止损过宽反而变差）。

## 待办（按价值排序）

1. **跨品种验证体制闸门**：Y / OI / M / C / RB 上跑 ER 闸门，看是普适还是特例
2. **把"不交易"做成状态机**：体制转弱立刻空仓，而不是只在信号时过滤
3. **补 2016–2021 高波动年**：验证趋势族是否只在 2022 型年份有效
